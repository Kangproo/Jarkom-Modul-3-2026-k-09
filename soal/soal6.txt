================================================================
PANDUAN PRAKTEK & DEMO: SOAL 6
Topik: Static DHCP Lease VIP kugisaki (10.68.3.99)
================================================================

[ TUJUAN SOAL ]
1. Memberikan fixed-address 10.68.3.99 untuk klien VIP kugisaki.
2. Mengikat alokasi berdasarkan MAC Address asli milik kugisaki (02:42:97:3f:1c:00).
3. Memastikan IP 10.68.3.99 berada di luar seluruh pool dinamis.

----------------------------------------------------------------
LANGKAH 1: CEK MAC ADDRESS kugisaki (SUDAH DILAKUKAN)
----------------------------------------------------------------
MAC Address asli eth0 kugisaki: 02:42:97:3f:1c:00


----------------------------------------------------------------
LANGKAH 2: DAFTARKAN HOST DI tengen
----------------------------------------------------------------
Buka terminal node: tengen
Copy-paste konfigurasi lengkap berikut ke terminal tengen:

cat > /etc/dhcp/dhcpd.conf << 'EOF'
option domain-name "k09.com";
option domain-name-servers 10.68.1.2, 10.68.1.3;
default-lease-time 600;
max-lease-time 7200;
ddns-update-style none;
authoritative;

# === SOAL 4: Network 2 (Divisi A) ===
class "pool1" {
    match if (option host-name = "itadori") or
             (substring(hardware, 1, 6) = 02:42:94:0f:6d:00);
}

class "pool2" {
    match if (option host-name = "zenin") or
             (substring(hardware, 1, 6) = 02:42:c5:24:d7:00);
}

# === SOAL 5: Network 3 (Divisi B) ===
class "short-lease" {
    match if (option host-name = "ino") or
             (substring(hardware, 1, 6) = 02:42:ae:72:7a:00) or
             (option host-name = "kusakabe");
}

class "long-lease" {
    match if (option host-name = "miwa") or
             (substring(hardware, 1, 6) = 02:42:eb:ee:d1:00);
}

# Subnet 4 (Local DC)
subnet 10.68.4.0 netmask 255.255.255.0 {
    option routers 10.68.4.1;
    option broadcast-address 10.68.4.255;
}

# Subnet 2 (Divisi A)
subnet 10.68.2.0 netmask 255.255.255.0 {
    option routers 10.68.2.1;
    option broadcast-address 10.68.2.255;
    option domain-name-servers 10.68.1.2, 10.68.1.3;
    option domain-search "k09.com";

    pool {
        allow members of "pool1";
        range 10.68.2.10 10.68.2.35;
    }

    pool {
        allow members of "pool2";
        range 10.68.2.70 10.68.2.95;
    }
}

# Subnet 3 (Divisi B)
subnet 10.68.3.0 netmask 255.255.255.0 {
    option routers 10.68.3.1;
    option broadcast-address 10.68.3.255;
    option domain-name-servers 10.68.1.2, 10.68.1.3;
    option domain-search "k09.com";

    # Short lease pool: 1800 detik (30 menit)
    pool {
        allow members of "short-lease";
        range 10.68.3.10 10.68.3.89;
        default-lease-time 1800;
        max-lease-time 1800;
    }

    # Long lease pool: 43200 detik (12 jam)
    pool {
        allow members of "long-lease";
        range 10.68.3.100 10.68.3.199;
        default-lease-time 43200;
        max-lease-time 43200;
    }
}

# === SOAL 6: Fixed Address VIP kugisaki ===
host kugisaki {
    hardware ethernet 02:42:97:3f:1c:00;
    fixed-address 10.68.3.99;
    option routers 10.68.3.1;
    option broadcast-address 10.68.3.255;
    option domain-name-servers 10.68.1.2, 10.68.1.3;
    option domain-search "k09.com";
}
EOF

# Restart server DHCP
service isc-dhcp-server restart


----------------------------------------------------------------
LANGKAH 3: RENEW LEASE DI kugisaki
----------------------------------------------------------------
Buka terminal node: kugisaki
Jalankan perintah ini untuk menarik IP tetap:

killall udhcpc 2>/dev/null
udhcpc -i eth0


----------------------------------------------------------------
LANGKAH 4: CARA DEMO KE ASISTEN (VERIFIKASI)
----------------------------------------------------------------
1. Di terminal kugisaki, jalankan:
   ip addr show eth0
   -> Tunjukkan ke asisten: IP tepat 10.68.3.99.

2. Di terminal tengen, tunjukkan konfigurasi host:
   cat /etc/dhcp/dhcpd.conf | grep -A 8 "host kugisaki"
   -> Tunjukkan: pemetaan MAC address ke fixed-address 10.68.3.99.

[ POIN PENJELASAN UNTUK DIUCAPKAN KE ASISTEN ]
"kugisaki adalah VIP yang memerlukan IP permanen. Kami menggunakan fitur
host reservation dengan mengikat MAC Address eth0 kugisaki (02:42:97:3f:1c:00) ke alamat 10.68.3.99.
Alamat ini berada di luar pool short-lease (.10-.89) dan long-lease (.100-.199),
sehingga dijamin tidak akan pernah bentrok dengan klien dinamis lainnya."
