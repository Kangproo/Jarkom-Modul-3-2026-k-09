================================================================
PANDUAN PRAKTEK & DEMO: SOAL 8
Topik: Packet Capture 4 Tahapan DHCP (DORA) & Verifikasi giaddr
================================================================

[ TUJUAN SOAL ]
1. Merekam transaksi DHCP saat klien meminta lease baru.
2. Memperlihatkan urutan DHCPDISCOVER -> DHCPOFFER -> DHCPREQUEST -> DHCPACK.
3. Memvalidasi nilai giaddr sesuai interface jichi yang menerima request.

----------------------------------------------------------------
PERINTAH PENGUJIAN
----------------------------------------------------------------

Pada tengen (10.68.4.10), mulai capture:
tcpdump -i eth0 -n -vvv 'port 67 or port 68'

Pada itadori, minta lease baru:
killall udhcpc 2>/dev/null
ip addr flush dev eth0
udhcpc -f -v -i eth0 -x hostname:itadori

Opsi -x hostname:itadori mengirim DHCP Host Name (Option 12), yang cocok
dengan class pool1. Opsi ini kompatibel dengan BusyBox udhcpc di Alpine.

----------------------------------------------------------------
HASIL AKTUAL DARI PACKET CAPTURE
----------------------------------------------------------------

Capture menunjukkan transaksi DORA lengkap dengan nilai berikut:

1. DHCPDISCOVER
   - Relay meneruskan request dari 10.68.4.1 ke DHCP server 10.68.4.10.
   - Gateway-IP/giaddr: 10.68.2.1.
   - Hostname: itadori.
   - MAC klien: 02:42:94:0f:6d:00.

2. DHCPOFFER
   - Server: 10.68.4.10.
   - Alamat yang ditawarkan (Your-IP): 10.68.2.10.
   - Gateway-IP/giaddr: 10.68.2.1.
   - Lease time: 600 detik.

3. DHCPREQUEST
   - Klien meminta alamat 10.68.2.10.
   - Server Identifier: 10.68.4.10.
   - Gateway-IP/giaddr: 10.68.2.1.

4. DHCPACK
   - Server mengonfirmasi lease untuk 10.68.2.10.
   - Gateway-IP/giaddr: 10.68.2.1.
   - Lease time: 600 detik.

Kesimpulan: keempat pesan DORA terlihat pada capture. Klien itadori berhasil
mendapatkan 10.68.2.10 dari Pool 1 (10.68.2.10-10.68.2.35), dan giaddr
bernilai 10.68.2.1 sesuai interface eth2 pada router jichi.

Catatan: lease time yang terlihat adalah 600 detik (10 menit), sesuai dengan
default-lease-time global di dhcpd.conf. Pool Network 2 tidak menetapkan
lease khusus. Pengaturan 1800 dan 43200 detik pada Soal 5 berlaku di Network 3.
