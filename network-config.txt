================================================================================
KUMPULAN NETWORK CONFIGURATION UNTUK SELURUH NODE GNS3
(Klik kanan Node di GNS3 -> Edit network configuration -> Paste isinya)
================================================================================
Dengan cara ini, konfigurasi disimpan di /etc/network/interfaces kontainer
sehingga TIDAK AKAN PERNAH HILANG saat node di-restart / di-stop-start.

--------------------------------------------------------------------------------
1. ROUTER UTAMA: jichi (ardhptr21/debinet:latest)
--------------------------------------------------------------------------------
auto lo
iface lo inet loopback

auto eth0
iface eth0 inet dhcp
    up sysctl -w net.ipv4.ip_forward=1
    up iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
    up service isc-dhcp-relay start

auto eth1
iface eth1 inet static
    address 10.68.1.1
    netmask 255.255.255.0

auto eth2
iface eth2 inet static
    address 10.68.2.1
    netmask 255.255.255.0

auto eth3
iface eth3 inet static
    address 10.68.3.1
    netmask 255.255.255.0

auto eth4
iface eth4 inet static
    address 10.68.4.1
    netmask 255.255.255.0


--------------------------------------------------------------------------------
2. DHCP SERVER: tengen (ardhptr21/debinet:latest)
--------------------------------------------------------------------------------
auto lo
iface lo inet loopback

auto eth0
iface eth0 inet static
    address 10.68.4.10
    netmask 255.255.255.0
    gateway 10.68.4.1
    up echo "nameserver 192.168.122.1" > /etc/resolv.conf
    up service isc-dhcp-server start
